# Hero images

Place the six species-card hero images in this folder, then edit each species in
`data.js`.

Example:

```js
portraitImage: "./assets/images/great-auk.jpg",
portraitFit: "cover",
portraitPosition: "35% center",
```

- `portraitFit: "cover"` fills the frame and may crop the edges.
- `portraitFit: "contain"` shows the complete image and may leave space around it.
- `portraitPosition` moves the focal point. Try `left center`, `center center`,
  `right center`, or a percentage such as `35% center`.
